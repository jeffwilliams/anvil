# Anvil Go API

Go package for interacting with Anvil through the REST API. Visit [anvil-editor.net](http://anvil-editor.net) for the latest documentation and downloads.

To use this package, you can do:

    go get github.com/jeffwilliams/anvil/api/go/anvil

and import it as:

    import "github.com/jeffwilliams/anvil/api/go/anvil"
